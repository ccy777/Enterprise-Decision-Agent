# DOC-ORG-001 企业画像与演示资料范围说明

版本：1.0
适用范围：华衡智能科技有限公司的企业身份、业务范围、演示资料和经营数据口径说明。
责任部门：总经理办公室；仓储管理部、采购管理部、销售运营部、客户服务部和信息安全办公室协同维护。

## 一、企业身份与性质

条款 ID：ENT-IDENTITY

本资料中的华衡智能科技有限公司是企业 Agent 项目的统一企业身份，用于把制度资料、产品名称、经营场景和问题答案保持在同一演示口径。用户也可称其为华衡智能、华衡科技、公司、本公司、这家公司、这个企业或示例企业；这些称呼仅指向本演示资料包，不能据此推断任何外部主体、注册地址、人员、客户或经营资质。该身份只服务于演示资料索引和问题理解，不构成现实主体识别，也不用于查询外部工商、信用、市场或人员信息，更不产生外部主体关系结论或现实经营判断，并以受控资料范围为限。

条款 ID：ENT-FICTIONAL-DEMO

华衡智能科技有限公司是一个虚构演示企业，不是对现实中同名或相近名称企业的声明。本知识库中的制度、产品、供应商、数值和业务描述均为项目测试与演示用途，不能作为真实企业政策、合同承诺、采购指令、产品规格、价格信息或合规意见。遇到需要现实世界核验的问题，应明确说明当前资料不提供该依据。

条款 ID：ENT-INDUSTRY

企业演示口径定位于智能设备制造与运营。资料覆盖的是围绕智能巡检终端及其配套附件形成的经营管理场景，而不是对制造工艺、工厂产能、专利、市场份额、财务业绩或外部行业排名的完整描述。行业表述只用于解释现有制度和数据问题的上下文。

条款 ID：ENT-PRODUCTS

当前演示产品包括产品 A、产品 B，以及分别配套的 A 型原装电池和 B 型原装电池；相关售后资料还涉及标准充电底座和工业增强底座。产品 A 与产品 B 是稳定的演示产品标识，不应自行扩展为未登记的新型号、技术参数或对外销售承诺。原装电池和整机在库存、保修及替换场景中应分别理解。

条款 ID：ENT-BUSINESS-LIFECYCLE

主要业务环节包括供应商准入与采购审批、库存监控与补货、销售折扣和区域履约控制、售后退换与维修受理，以及与这些环节相关的经营分析。库存紧张时会结合补货、交付和售后替换进行风险判断；这一说明不表示 Agent 可以自动下单、分配库存或改变任何业务记录。

条款 ID：ENT-DEPARTMENTS

仓储管理部负责库存口径、盘点和安全线监控；供应链中心负责趋势、到货计划和补货协调；采购管理部负责供应商准入与采购审批；销售运营部负责销售订单和交付影响复核；客户服务部负责保修、退换和维修受理。各部门职责以现有制度资料为准，概览不替代具体制度中规定的阈值、审批条件或例外处理。

条款 ID：ENT-KB-COVERAGE

当前知识库覆盖客户服务、销售、库存、采购、财务、人力资源和信息安全治理等制度性资料，并保留相应的条款来源。知识回答应以可检索的资料为依据并附带来源标记；若多个制度适用，应说明所依据的资料范围，而不是把概览内容当作全部制度细节。

条款 ID：ENT-DATA-COVERAGE

当前经营数据覆盖库存预警、补货审批、与经营分析相关的已接入业务数据，以及知识与数据结合的综合风险判断。数据回答只能依据当前受控数据源返回的结果和可用字段；没有接入的数据、历史记录或明细不能通过推测补齐，也不能把知识库中的制度文字误称为实时经营事实。

条款 ID：ENT-EXCLUSIONS

当前资料不包含通用互联网信息、实时市场新闻、未登记产品、真实客户或员工档案、未接入系统的订单明细、完整制造工艺、任意法律结论或外部企业背景。对于超出这些资料和数据范围的问题，Agent 应说明缺少依据或该请求不受支持，而不应编造答案、来源或数字。

条款 ID：ENT-DATA-STATUS

本资料包的演示数据版本为 1.0，制度文件的生效日期统一为 2026-01-01。版本和日期只表示本演示资料包的维护口径，不表示真实企业的制度发布日期、数据更新时间或实时库存时间点。使用者应把回答理解为当前受控资料范围内的说明，并结合实际业务系统另行核验。

资料维护时，应保持企业名称、产品、部门和条款一致。概览不改写库存阈值、采购审批、保修期限或数据权限等具体规则。具体问题仍应检索对应制度或数据证据；未列事实不得因名称相近而自动成立。演示资料不建立真实人员、客户、地点或联系方式档案。
