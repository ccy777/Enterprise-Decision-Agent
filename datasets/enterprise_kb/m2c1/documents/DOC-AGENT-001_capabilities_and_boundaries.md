# DOC-AGENT-001 企业 Agent 能力与使用边界说明

版本：1.0
适用范围：华衡智能科技有限公司演示资料包中的企业 Agent 提问、取证、数据分析和操作边界。
责任部门：总经理办公室；信息安全办公室、业务数据责任部门和制度资料维护部门协同维护。

## 一、可回答的依据与模式

条款 ID：AGENT-NATURAL-LANGUAGE

企业 Agent 支持以自然语言提出与当前企业资料相关的问题。常见表达可询问企业制度、产品和部门职责、库存预警、补货审批、售后规则、经营数据或综合风险；同一问题可以使用“公司”“企业”“本公司”“这个企业”“Agent”“企业 Agent”“决策助手”或“企业智能助手”等演示称呼。能否回答取决于当前知识库和受控经营数据是否存在可核验依据，而不取决于提问措辞是否完全一致。提问可补充业务条件，但不会扩大资料与数据源的覆盖范围，也不会触发业务写操作、自动通知或其他执行动作。

条款 ID：AGENT-KNOWLEDGE

Knowledge 能力用于检索当前知识库中的企业资料和制度条款，例如企业画像、库存规则、采购审批、销售、售后、财务、人力资源和信息安全治理。回答应依据检索到的资料说明适用范围；资料没有给出某个参数、流程或事实时，不能用常识、猜测或未引用的内容补充。

条款 ID：AGENT-DATA

Data 能力用于分析当前接入的受控经营数据，例如库存预警、补货审批和其他已接入的经营分析数据。数据回答应以查询结果中的可用字段、时间范围和汇总口径为准；数据源未提供的实时状态、完整历史、业务原因或外部信息不能被假定存在。数据分析只解释现有结果，不改变源数据。

条款 ID：AGENT-MIXED

Mixed 能力用于同时使用制度知识和经营数据进行综合判断，例如把库存预警与补货制度、交付影响或售后替换场景一起说明。Mixed 回答必须区分制度依据与数据事实，并在任一部分缺少依据时说明限制；它不是对未来经营结果的保证，也不替代人工审批、库存分配或业务决策。

条款 ID：AGENT-EVIDENCE

回答中的引用标记表示该结论可追溯到当前知识库资料或受控数据分析所使用的证据。引用不是互联网链接、外部认证、实时业务回执或对全文的概括；使用者应结合引用所指的资料范围理解结论。若无法形成可核验的引用，Agent 应明确说明当前没有足够依据，而不能生成看似可信的来源。

条款 ID：AGENT-UNSUPPORTED

当问题不在当前知识库或受控经营数据范围内、关键条件缺失、资料之间无法支持确定结论，或请求要求超出已定义能力时，Agent 应说明不可回答、信息不足或请求不受支持。它可以指出需要补充的业务条件或资料类型，但不能把缺失内容编造成企业事实、实时数据、审批结果或专业意见。

条款 ID：AGENT-NO-WEB

企业 Agent 不支持通用互联网搜索、网页浏览、实时新闻检索或以外部网站作为回答依据。它也不把公开网络信息自动并入当前企业资料；即使问题包含公司、产品或行业名称，回答范围仍受已登记知识库和受控经营数据源限制。

条款 ID：AGENT-NO-CHAT

企业 Agent 不提供任意闲聊、开放式百科问答、未受证据约束的创作或长期用户画像。session 标识仅服务于当前正式请求的受控处理，不表示系统会建立跨请求的个人档案、偏好推断或长期记忆。用户需要一般性讨论时，应理解该请求可能不属于本演示的企业知识与数据能力范围。

条款 ID：AGENT-NO-WRITE

企业 Agent 不执行写数据库、修改订单、创建采购申请、自动下单、发起付款、变更库存、调整审批、发送通知或其他业务写操作。它可以解释制度、呈现受控数据分析和提示风险，但所有实际业务动作仍须由授权人员在相应业务系统中完成并遵循既有审批制度。

条款 ID：AGENT-VERSION-DATA

当前演示资料和数据口径为版本 1.0；知识库制度文件的统一生效日期为 2026-01-01。该版本标识用于界定本演示的资料范围，不承诺实时刷新、完整历史覆盖或真实企业同步。需要最新运营事实时，应以获授权的业务系统和人工复核为准，不能仅凭演示回答执行操作。

Agent 是受证据约束的企业知识与数据助手，不拥有自主业务权限。给出产品、部门、时间范围、库存状态或审批条件有助于定位资料；系统只在已有资料或受控查询支持时回答并保留引用。无法取得依据时的拒答或限制说明是正常边界，不代表系统已执行后台动作。
